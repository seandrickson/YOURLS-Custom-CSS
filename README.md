YOURLS Custom CSS Plugin
========================

Add custom CSS to your YOURLS admin area. Some (very) opinionated CSS has already been added. Feel free to edit the CSS in this plugin.

Installation
------------

Move the `custom-css` folder into the `/user/plugins` folder. Then, activate the plugin in the admin interface. Open up the `plugin.php` file and start tweaking the CSS!

Requirements
------------

- [YOURLS](https://yourls.org/) 1.10 or newer (tested against 1.10.6)
- PHP 8.1 or newer (required by YOURLS 1.10)
